# Repository Guide

## Overview

Static HTML blog with minimalist white theme. Single-file site deployed via GitHub Pages.

## Structure

- `index.html` — Complete blog (HTML + CSS + JS in one file)

## Development

No build step. Edit `index.html` directly. Open in browser to preview:

```bash
open index.html
```

## Deployment

GitHub Pages serves from root. Changes to `main` auto-deploy to `https://qwq202.github.io/131/`.
